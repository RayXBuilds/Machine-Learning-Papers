# 每日收录

[首页](../../README.md) · [主题目录](../../papers/README.md) · [收录规范](../../CONTRIBUTING.md)

每日收录保存在 `YYYY/MM/YYYY-MM-DD.md`，按北京时间记日。记录只包含当天新增/实质修订文章的链接、主题和一句话收录理由；全文导读统一存放在 `papers/<主题>/`。

## 2026 年

- [10 月](2026/10/README.md)：当前新增 11 篇；[2026-10-29 收录详情](2026/10/2026-10-29.md)。

目录迁移不计为新增论文。

有新增后在此按年份链接月度索引 `YYYY/MM/README.md`，月度索引按日期倒序链接日报。没有新增不创建空日报；同日重跑合并去重。已有文章更新原文件，不重复创建。
