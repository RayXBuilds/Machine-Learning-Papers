# Visualizing Data using t-SNE

- 仓库内 PDF：[打开全文](../../pdfs/classical-ml/2008-tsne.pdf)（JMLR 期刊版）。

## 解决的问题

把高维数据画在平面上时，如何减少大量邻点挤在一起、局部关系难以辨认的问题？

## 主要方法

将高维相似度转成邻接概率，在低维使用重尾分布定义相似度，再最小化两种概率分布间的 KL 散度。

## 贡献与局限

重尾分布给中等距离的点留出空间。图上的簇间距离与面积取决于目标和参数，不宜直接解释成原空间的度量。

## 前置知识与阅读重点

先了解 KL 散度。比较一对高维近邻被画远和一对远点被画近时，目标函数分别如何响应。

## 收录理由

提供阅读嵌入图的依据，尤其适合检验可视化中哪些几何结论有支持。
