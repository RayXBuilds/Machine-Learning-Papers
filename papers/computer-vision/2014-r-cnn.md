# Rich feature hierarchies for accurate object detection and semantic segmentation

## 解决的问题

如何把只输出整图类别的卷积网络用于定位多个目标，并利用数量有限的检测标注？

## 主要方法

先生成候选框，把各区域变换到网络输入尺寸，提取经检测数据微调的卷积特征，再训练类别分类器并细化框坐标。

## 贡献与局限

原文展示了分类预训练向检测迁移的收益。逐区域运行卷积会重复处理重叠区域，计算量随候选数上升。

## 前置知识与阅读重点

先了解分类预训练、IoU 和平均精度。沿单个候选框追踪微调、SVM 打分与边框回归的训练目标。

## 收录理由

为理解后续检测器为什么共享整图特征提供基线。
