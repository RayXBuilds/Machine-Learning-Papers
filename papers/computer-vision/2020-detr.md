# End-to-End Object Detection with Transformers

## 解决的问题

怎样让检测器直接输出一组物体，减少对锚框设计和重复框后处理的依赖？

## 主要方法

固定数量的对象查询在解码器中读取图像特征，用二分图匹配给预测分配真实目标，再计算分类与框回归损失。

## 贡献与局限

一对一匹配为端到端集合预测提供了训练目标。原版在小目标上较弱，训练收敛也需要较长周期。

## 前置知识与阅读重点

先熟悉检测框和匈牙利算法。以两个物体和三个查询为例，写出匹配后哪个查询学习无物体类别。

## 收录理由

展示将无序集合的监督转化为可训练目标的方法。
