# Momentum Contrast for Unsupervised Visual Representation Learning

## 解决的问题

对比学习需要大量负例，如何避免字典大小被单次训练的批量限制？

## 主要方法

队列跨批保存键向量，键编码器缓慢跟随查询编码器更新，使不同时刻生成的键保持相对一致。

## 贡献与局限

作者在分类与检测等迁移任务上检验了表示。队列越长，最旧的键与当前编码器可能相差越大。

## 前置知识与阅读重点

先熟悉对比损失。追踪一对增强视图，区分由梯度更新的参数、由动量更新的参数和出队的向量。

## 收录理由

补充 SimCLR 的对照，帮助区分负例数量和表示一致性。
