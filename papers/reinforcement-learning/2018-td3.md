# Addressing Function Approximation Error in Actor-Critic Methods

[主题目录](README.md) · [年份导航](../../docs/years/README.md) · [学习路线](../../docs/reading-paths.md)

- 作者：Scott Fujimoto、Herke van Hoof、David Meger。
- 年份与版本：按 ICML 2018 正式发表年份归档。arXiv 初稿提交于 2018 年 2 月。
- 原始来源：[ICML 会议版](https://proceedings.mlr.press/v80/fujimoto18a.html) · [作者预印本](https://arxiv.org/abs/1802.09477)。
- 官方代码：[作者项目](https://github.com/sfujim/TD3)。

## 解决的问题

当策略追逐近似价值函数的高点时，估值误差如何在连续控制中累积？

## 主要方法

双评论器取较小的目标估值，目标动作加入小幅截断噪声，并让策略比评论器更新得慢。

## 贡献与局限

连续控制实验和消融支持这三项改动。取较小值会引入偏低估计，读结果时需要同时观察偏差和最终回报。

## 前置知识与阅读重点

先掌握 Bellman 目标和确定性策略梯度。把更新式中的目标策略、在线策略及两个评论器分别标出。

## 收录理由

补足连续动作价值估计，可与 SAC 的熵正则目标比较。
